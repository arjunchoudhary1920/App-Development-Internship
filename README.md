# StudyMate — App Concept and Screen Flow

## Task 1: App Concept
StudyMate is a simple student productivity app for organizing assignments, study sessions, and deadlines in one place.

### Target users
School and college students who need a lightweight way to remember homework, plan study time, and track completed work.

### Problem and solution
Deadlines often get scattered across notebooks, messages, and calendars. StudyMate brings tasks, due dates, and a weekly plan into one clear interface.

### Five primary screens
1. **Dashboard:** Today's priorities, upcoming deadlines, and progress summary.
2. **My Tasks:** Assignments with due dates, subjects, priorities, and completion states.
3. **Calendar:** Weekly overview of study sessions and deadlines.
4. **Add Task:** Form for task title, subject, due date, and priority.
5. **Profile & Settings:** Notification, appearance, and accessibility preferences.

### Navigation flow
- The app opens to Dashboard.
- Dashboard → My Tasks to view or complete assignments.
- Dashboard or My Tasks → Add Task; Save → My Tasks.
- Dashboard → Calendar to review the week and select a date.
- Dashboard → Profile & Settings; Back → Dashboard.

### Accessibility
- Clear headings and descriptive labels.
- High-contrast text; priority is not communicated by color alone.
- Semantic HTML, visible keyboard focus, and a skip link.
- Responsive layout for mobile and desktop.
- Respects reduced-motion preferences.

### Preview
Open [index.html](index.html) in a browser to view the responsive screen-flow mockup. This is a static concept prototype; form actions do not store data.

### Tech stack
HTML5 and CSS3. No dependencies or build step required.
