# Task 1: App Concept and Screen Flow

## App name: StudyMate — Student Task Planner

### App idea
StudyMate is a simple productivity app that helps students organize assignments, exams, study sessions, and deadlines in one place.

### Target users
School and college students who want a clear, low-friction way to plan their academic work and avoid missing deadlines.

### Problem statement
Students often track deadlines across notebooks, chats, and calendars. StudyMate brings tasks, due dates, and progress into one easy-to-scan interface.

### Core features
- View today's tasks and upcoming deadlines
- Add tasks with a subject, due date, and priority
- Review tasks in a calendar
- Track completed work and weekly progress
- Edit a simple profile and preferences

### Primary screens (5)
1. **Dashboard** — summary of today's tasks, progress, and next deadlines.
2. **My Tasks** — all tasks, searchable and filterable by status or priority.
3. **Add/Edit Task** — task title, subject, due date, priority, and notes.
4. **Calendar** — monthly overview of assignments and exams.
5. **Profile & Settings** — user preferences, reminders, and app information.

### Navigation flow
- App opens to **Dashboard**.
- Bottom navigation links Dashboard, My Tasks, Calendar, and Profile.
- The **+ Add Task** action from Dashboard or My Tasks opens Add/Edit Task.
- Saving a task returns to the screen where the user started and updates the task list/calendar.
- Selecting a task opens its details for editing or marking it complete.

### Accessibility considerations
- Semantic headings and labeled form controls
- Keyboard-accessible navigation and visible focus styles
- High-contrast text and controls
- Status is conveyed with text as well as color
- Responsive layout for mobile, tablet, and desktop

### Deliverables
- `index.html` — clickable, responsive concept prototype
- `style.css` — visual styles
- `screen-flow.md` — screen descriptions and navigation flow

This is a front-end concept prototype. Task data is demo data and is not stored on a server.
